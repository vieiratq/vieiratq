- **[Sistema de Ponto Eletrônico](https://github.com/vieiratq/sistema_ponto_eletronico):** Sistema cliente-servidor para autenticação de empresas, registro de pontos e persistência de dados utilizando Node.js, TypeScript, Express e PostgreSQL.
